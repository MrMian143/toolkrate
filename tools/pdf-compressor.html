PDF Compressor

Reduce a PDF's file size, right in your browser. Best suited to scanned documents or PDFs full of photos.

This works by redrawing each page as a compressed image and rebuilding the PDF from those images — the same approach most "compress PDF" tools use. It shrinks scanned pages and image-heavy PDFs very well. The trade-off: text in the compressed PDF is no longer selectable or searchable, since each page becomes a picture of itself. If you need to keep selectable text, this isn't the right tool for that file — only use it when a smaller file matters more than searchable text.
