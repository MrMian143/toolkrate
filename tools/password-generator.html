Password Generator

Generate a strong random password using your browser's cryptographic random number generator. Nothing is sent anywhere.

Why this generator is safe to use

Passwords are generated using crypto.getRandomValues, the browser's cryptographically secure random number source, not Math.random. Generation happens locally on your device — the password is never transmitted or logged anywhere.
