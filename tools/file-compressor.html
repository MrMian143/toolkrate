File Compressor

Pick any file. This detects what kind it is and compresses it the right way — images, PDFs, videos and everything else each need a different approach, so one file picker here quietly uses the correct one.

PDFs are compressed by redrawing each page as an image, so text becomes non-selectable afterwards — best for scanned or image-heavy PDFs.
Video needs a real encoder, so the first time you compress a video here, a ~25–30 MB engine loads in the background (one-time per visit). Works best on desktop.
This file type doesn't have a lossy compression trick that keeps it in the same format, so it's bundled into a lossless .zip instead — a safe way to shrink text-based files (docs, spreadsheets, code) and to package the file for sending. Already-compressed formats (most photos, videos, audio, zipped files) won't shrink much further this way.

Why one tool, several methods

A photo, a PDF and a video don't get smaller the same way — each format needs its own technique to actually shrink without just renaming the problem. Rather than force everything through one lossy trick (which would either fail silently or wreck the file), this tool picks the method that matches what you dropped in: canvas re-encoding for images, page rasterization for PDFs, a real video encoder for video, and lossless zipping for anything else. If you'd rather go straight to a dedicated page with more controls, the Image Compressor, PDF Compressor, Video Compressor and Zip Files tools are also on this site.
